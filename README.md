# homebrew-tap

Homebrew tap for [@fabiosoft](https://github.com/fabiosoft) projects.

## Install

```bash
brew install fabiosoft/tap/luciq-instabug-mcp
```

Or, equivalently:

```bash
brew tap fabiosoft/tap
brew install luciq-instabug-mcp
```

## Formulas

| Formula | Description |
|---|---|
| [`luciq-instabug-mcp`](Formula/luciq-instabug-mcp.rb) | Bridge that turns a public Luciq (Instabug) bug-report URL into JSON, raw logs and screenshot — REST + MCP |
